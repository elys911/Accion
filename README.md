# Acción del Universo

A unified covariant field-theoretic action formulated in curved spacetime, combining scalar, fermionic, and gauge sectors with gravitational curvature via a non-minimal coupling structure. The model explores spontaneous symmetry breaking, mass emergence, and early-universe cosmology including inflation, reheating, and vacuum evolution.
